# 공간 디자인 계획 — 새벽의 찜질방

> **상태**: 5단계까지 구현. 남은 것은 중급 안드로이드 실기기 측정(`docs/PERF_CHECKPOINT.md`)과 이변 찾기 모드 자체의 구현(PRD 14절, `src/core/anomaly`는 아직 없다). 평면 좌표의 원본은 `src/spaces/jjimjilbang/layout.ts`다. 공간 ID `jjimjilbang` (`?space=jjimjilbang`, `src/spaces/jjimjilbang`, `art/blender/jjimjilbang`).
> [물 공간 아이디어](water-space-ideas.md) 3번 후보를 구체화한 문서다. AGENTS.md의 절대 규칙·디자인 원칙과 PRD 12~13절의 4구역 존 매핑 방식을 그대로 상속한다.
> 좌표와 수치는 화이트박스용 초안이다. 조명·재질·세부 좌표는 Cursor에서 눈으로 보며 조정한다.

## 1. 컨셉

**"24시간 영업이라 불이 꺼진 적 없는 찜질방의 새벽 네 시."**

찜질방은 원래 문을 닫지 않는다. 그래서 "폐장 후"가 아니라 **"영업 중인데 사람만 통째로 빠진"** 상태가 위화감의 핵심이다. 장판은 따뜻하고, 매트는 방금 누군가 일어난 모양으로 눌려 있고, 식혜 냉장고는 불이 켜진 채 비어 있다. 안마의자 한 대만 혼자 돌아간다.

**센토와 겹치지 않게 하는 원칙**

| | 심야 센토 | 새벽의 찜질방 |
|---|---|---|
| 열 | 습한 열기, 김 | 마른 열기, 온돌, 아지랑이 |
| 빛 | 백열등 단색의 따뜻함 | 누런 형광등 + 방마다 다른 색(암염 분홍, 황토 적갈, 얼음 청백, 불가마 틈새 빨강) |
| 물 | 주인공 (대욕조) | 조연 (족욕 수로, 얼음방 성에, 식혜) |
| 재질 | 타일, 편백 | 장판, 황토, 암염, 숯, 대리석, 카펫 |
| 구조 | 남/여 거울상 | 큰 홀 하나에 작은 방들이 가지처럼 달린 구조 |
| 문화 | 일본 센토 | 한국 찜질방 (양머리 수건, 구운 계란, 식혜, 토굴 수면실) |

탈의실과 탕은 만들지 않는다. 남/여 탈의실 문은 셔터가 내려가 있고, 플레이어는 옷을 입고 다니는 **공용 찜질 층**만 걷는다. 노출 연상 요소가 원천적으로 없어 3스토어 등급에도 유리하다.

## 2. 4구역 존 매핑

| 원작 존 | 찜질방 버전 | 역할 |
|---|---|---|
| 정문 광장 | 지하 카펫 복도·카운터·신발장 | 진입점, 톤 설정. 엘리베이터에서 내리면 호텔 카펫이 장판으로 바뀐다 |
| 미드웨이 | 찜질 골목 (족욕 수로 + 테마방 4개) | 배회의 중심축. 가운데 수로가 길잡이이고 양옆으로 방이 분기한다 |
| 먹거리 골목 | 대청마루 홀 | 천장이 높고 개방된 공간, 물리 오브젝트 밀집. 매트, 목침, 매점, 안마의자, TV |
| 백스테이지 | 토굴 수면실·세탁실·불가마 아궁이 뒤편 | 리미널 효과가 가장 짙은 구역. 낮은 천장, 반복되는 굴, 직원 통로 |

### 배치 (Three 좌표, 플레이어는 -Z로 들어간다)

```
                    z=-40 ┌───────────────────────────┬──────────────┐
                          │  TV 벽        매점        │              │
                          │                           │  토굴 수면실 │
                          │       대청마루 홀         │  (2단 벌집)  │
                          │   x[-16,16] · 천장 6 m    │ x[16,30]     │
                          │                           ├──────┬───────┤ z=-24
                          │ 안마의자 열      만화서가 │직원  │세탁실 │
                    z=-12 └────────┐         ┌────────┤통로  │       │
              ┌───────────┐        │  찜질   │┌──────┐│x[17, ├───────┘ z=-10
              │ 황토방    ├────────┤  골목   ├┤얼음방││ 21]  │
              ├───────────┤        │ ║수로║  │└──────┘│      │
              │ 소금방    ├────────┤ x[-6,6] ├┬──────┐│아궁이│
              └───────────┘        │ 천장 3.2││불가마├┼철창  │
                    z=12  ┌────────┴─────────┴┴──────┘│      │
                          │ 신발장   입구   카운터 ◄──┴──────┘ (카운터 뒤 문)
                    z=26  └──── 엘리베이터 (스폰) ─────┘
```

| 구역 | 범위(초안) | 천장 |
|---|---|---|
| 입구 | x[-5,5] · z[12,26] | 2.6 m |
| 찜질 골목 | x[-6,6] · z[-12,12] | 3.2 m |
| 소금방 / 황토방 | x[-14,-6] · z[3,11] / z[-9,-1] | 2.4 m |
| 불가마 / 얼음방 | x[6,16] · z[1,11] / x[6,12] · z[-9,-3] | 돔 4 m / 2.2 m |
| 대청마루 홀 | x[-16,16] · z[-40,-12] | 6 m |
| 토굴 수면실 | x[16,30] · z[-40,-24] | 2.4 m |
| 직원 통로·세탁실 | x[17,21] · z[-24,12] / x[21,30] · z[-24,-10] | 2.2 m |

**고리 동선**: 입구 → 골목 → 홀 → 수면실 → 직원 통로 → 카운터 뒤 문 → 입구. 막다른 길 없이 한 바퀴 돌 수 있고, '이변 찾기' 모드의 고리 구간으로도 그대로 쓸 수 있다.

**고정하는 것(거시 구조)**: 수로 위치, 테마방 4개의 순서, 불가마 돔, 매점·TV 벽 방향, 토굴 벌집.
**재시드하는 것**: 매트·목침 흩어짐, 계란·식혜 캔 위치, 켜진 토굴 등 위치, 형광등 깜빡임, 혼자 도는 안마의자가 몇 번째인지.

### 구역별 구성과 위화감

**입구 — 지하 카펫 복도·카운터**
- 엘리베이터 문(닫힘, 층 표시등 B2) 앞에서 시작한다. 호텔 카펫 복도가 짧게 이어지다가 단 하나를 올라서면 장판이 된다.
- 동쪽 카운터에는 접힌 찜질복 더미(주황·분홍)와 열쇠 팔찌 걸이가 있고, 서쪽 벽은 번호 칸 신발장이 채운다. 카운터 뒤 문은 직원 통로(x[5,17] · z[12,16] 연결부)로 이어진다.
- 위화감: 신발장이 거의 꽉 차 있다(신발은 있는데 사람이 없다). 열쇠 팔찌 걸이는 한 칸만 비었다.

**찜질 골목 — 족욕 수로와 테마방**
- 골목 한가운데에 얕은 족욕 수로(x[-1.5,1.5] · z[-9,9])가 길게 흐른다. 양옆이 완만한 경사라 어디서든 걸어 들어가고 나온다. 돌다리 두 개(z=±5)로 건널 수도 있다. 수로 안에서는 돌다리 밑을 지나지 못하므로 옆 경사로 올라와 돌아간다.
- 방마다 문 위 온도 표시판과 고유한 빛이 새어 나와 멀리서도 구분된다.
  - **소금방**: 암염 벽돌 백라이트(분홍), 바닥 소금 자갈. 모래시계들이 전부 같은 높이에서 멈춰 있다.
  - **황토방**: 적갈색 흙벽, 멍석. 벽시계가 골목 시계와 다른 시각이다.
  - **불가마**: 돔형 한증막, 낮은 아치 입구, 가마니 방석. 온도계 바늘이 아주 천천히 오르내린다.
  - **얼음방**: 성에 낀 냉각 배관, 청백색 빛. 찬 안개가 바닥으로 흘러 문턱 밖으로 넘친다. 문 유리 안쪽 성에가 동그랗게 닦여 있다.
- 위화감: 수로의 편백 볼이 물이 흐르는 방향과 상관없이 한곳에 모여 있다.

**대청마루 홀**
- 누런 장판이 넓게 깔린 높은 홀. 매트와 목침이 여기저기 놓였고 전부 방금 일어난 모양으로 눌려 있다.
- 북벽 TV 여러 대는 화면조정 무늬를 무음으로 띄운다. 매점은 불이 켜져 있고 식혜 냉장고는 비었다. 구운 계란 바구니에는 계란이 가득하다.
- 서벽 안마의자 열 중 한 대만 혼자 작동한다. 휴대폰 충전함에는 표시등만 깜빡인다.
- 위화감: 양머리 수건 하나가 매트 위에 가지런히 놓여 있다. 계란 껍질은 한 접시에만 깔끔하게 모여 있다.

**백스테이지 — 토굴 수면실·세탁실·아궁이**
- 수면실은 2단 벌집형 토굴이 벽 가득 반복된다(화이트박스에서는 굴 안으로 들어가지 못한다. 들어갈 수 있게 할지는 2단계 모델에서 정한다). 조명이 거의 없고 굴 번호판만 희미하다. 굴 번호가 하나 건너뛴다. 굴 하나만 안쪽 등이 켜져 있는데 들어가 보면 다른 굴과 똑같다.
- 세탁실에는 찜질복·수건 더미와 돌아가는 세탁기 한 대. 직원 통로를 따라 내려가면 불가마 뒤편 아궁이가 나온다. 철창 너머로 불가마 안쪽이 보이지만 건너갈 수 없다(센토 보일러실 철창과 같은 문법).
- 통로 끝 문은 카운터 뒤로 이어진다.

## 3. 상호작용 (새 액션 추가 없음)

밀기/끌기 하나만 쓴다.

| 오브젝트 | 구역 | 메모 |
|---|---|---|
| 접이식 매트 | 홀, 수면실 | 납작하고 가볍다. 인스턴싱 대상 |
| 목침(나무 베개) | 홀, 수면실, 황토방 | 구르지 않는 직육면체 |
| 구운 계란 | 홀(매점) | 잘 구른다. 수로에 넣으면 가라앉는다 |
| 식혜 캔 | 홀 | 구른다. 물에 뜬다 |
| 편백 볼 | 수로 | 부력으로 떠다닌다 (`useBuoyancy` 재사용) |
| 족욕 바가지 | 골목 | 센토 `oke`와 같은 물리, 플라스틱 재질 |
| 수거 카트 | 입구, 세탁실 | 센토 `towel_cart`와 같은 물리 |
| 가마니 방석 | 불가마 | 납작한 판 |

- **족욕 수로**: 걸어 들어가는 얕은 물(바닥 -0.25, 수면 -0.12). `core/world/water`의 물 영역으로 등록해 살짝 느려지기만 한다. 수영 없음.
- **불가마·얼음방**: 들어가면 안개 색과 소리만 바뀐다. 체온·시간 제한 같은 규칙은 넣지 않는다.
- 안마의자, TV, 세탁기는 조작할 수 없다(혼자 움직이는 것을 바라보기만 한다).

## 4. 오디오

PRD 06절 원칙을 계승한다. 대사·가사·내레이션 없음.

| 소리 | 위치 | 구현 |
|---|---|---|
| 온돌 보일러 저음 | 전역 베드 | `noiseLoop` 저역 |
| 족욕 수로 순환(졸졸) | 골목 | 공간음 2~3점 |
| 불가마 장작 타닥 | 불가마 안, 아궁이 | 무작위 간격 클릭 |
| 냉동기 윙 + 성에 딱 소리 | 얼음방 | `noiseLoop` 고역 + 드문 틱 |
| 안마의자 롤러 주기음 | 홀 서벽 | 느린 LFO. 시드로 고른 한 대에서만 |
| 식혜 냉장고 컴프레서 | 매점 | 켜졌다 꺼지는 주기 |
| 매점 라디오 | 매점 | 가사 없는 트로트 반주에 피치 워블(디튠 + LFO) |
| TV 정파 잡음 | TV 벽 | 아주 작게. 가까이 가야 들린다 |
| 세탁기 회전 | 세탁실 | 저음 주기음 |
| 벽시계 초침 | 수면실 | 수면실은 이 소리 외에 거의 무음 |

수면실에 들어서면 전역 베드를 줄여 "방음된 듯한 정적"을 만든다. 오디오 원본 녹음은 코드 작업 범위 밖이므로 1차는 센토처럼 합성음(`core/audio/spatial`)으로 만든다.

## 5. 내러티브 파편

설명하거나 완결짓지 않는다. 글자는 숫자와 짧은 표지 위주로 쓴다.

- **요금표**: 주간/야간 요금과 날짜가 서로 맞지 않는다.
- **카운터 장부**: 입장 칸에만 숫자가 쌓여 있고 퇴장 칸은 비어 있다.
- **열쇠 팔찌**: 분실물 상자에 하나. 번호가 신발장에 없는 번호다.
- **방마다 다른 시계**: 골목, 황토방, 홀, 수면실의 시각이 전부 다르다.
- **매점 외상 메모**: 식혜 개수만 바를 정(正) 자로 빼곡하다.
- **만화책 한 권**: 서가 앞에 펼친 채 엎어져 있다.
- **양머리 수건**: 늘 같은 자리의 매트 위에 가지런히 놓여 있다.
- **수면실 '정숙' 팻말**: 켜진 토굴 앞에만 하나 더 걸려 있다.
- **센토와의 고리(선택, 미구현)**: 분실물 상자에 케로린 바가지 하나. 두 공간이 이어져 있다는 암시만 남긴다. 넣을지 정해지지 않아 아직 넣지 않았다.

## 6. 톤 관리 메모

- 핵심은 **"따뜻하고 조용하고 편한데, 여긴 원래 사람이 가득해야 하는 곳"**이다. 어둡게 만들지 않는다. 홀은 오히려 밝다.
- 사람·실루엣·손자국은 넣지 않는다. 흔적은 눌린 매트, 가지런한 수건, 닦인 성에처럼 사물의 상태로만 남긴다.
- 점프스케어·추격 AI 금지. 혼자 움직이는 것(안마의자, 온도계, 세탁기)은 느리고 규칙적이어야 한다.
- 바깥이 없는 지하 공간이다. 창문을 두지 않고 엘리베이터 문도 열리지 않는다.

## 7. 기술 계획

### 재사용과 선행 리팩터링

`spaces/jjimjilbang`은 `spaces/bathhouse`를 import할 수 없다(`npm run check:spaces`). 재사용하려는 것 중 일부가 아직 센토 폴더 안에 있어서 먼저 `core`로 올려야 한다.

| 대상 | 현재 위치 | 조치 |
|---|---|---|
| 물 영역·감속 | `core/world/water.ts`, `PlayerController` | 그대로 사용 |
| 부력, 끌기 | `core/physics/useBuoyancy`, `core/objects/useDraggable` | 그대로 사용 |
| 공간음·물방울·잡음 | `core/audio/spatial` | 그대로 사용 |
| 수면 셰이더 | `bathhouse/Water.tsx` | `core/world/Water.tsx`로 이동 (core만 의존하므로 이동만 하면 된다) |
| 김 파티클 | `bathhouse/Steam.tsx` | `core/world/Steam.tsx`로 이동. 얼음방용으로 색·하강 방향 옵션 추가 |
| 박스·바닥·벽·천장·모듈 배치 | `bathhouse/BathKit.tsx` | 공간 무관 부분(`Box`, `Floor`, `Ceiling`, `Wall`, `Model`, `ModelRow`, `ModuleFloor`, 표면 재질 훅)을 `core/world/kit`로 추출하고 공간 ID를 인자로 받게 한다. `TileWall`, `WarmLamp`, 팔레트는 센토에 남긴다 |
| Blender 공용 헬퍼 | `art/blender/lib/bath_common.py`, `lib/quality.py` | 그대로 사용. 장판·황토·암염 재질 함수만 추가 |

이 리팩터링은 센토 동작을 바꾸지 않아야 하므로 별도 커밋으로 하고, 센토 화면이 전과 같은지 확인한 뒤 찜질방 작업을 시작한다.

### 새 모델 (`art/blender/jjimjilbang/*.py`)

- **표면** (완료): `surfaces` — 장판, 카펫, 회벽, 콘크리트, 황토, 가마 벽돌, 암염 벽돌, 숯벽, 수로 돌, 얼음방 패널, 나무 2종. 바닥·벽은 모듈 모델 없이 박스에 이 재질을 크기대로 반복해 입힌다(`JjimKit`의 `surface`). 족욕 수로도 같은 방식이라 별도 모델이 없다.
- **랜드마크** (완료): `kiln_dome`(불가마 벽돌 볼트 천장), `cave_bank`(토굴 2단 모듈), `counter`, `shoe_locker`
- **랜드마크** (완료): `snack_bar`. TV 벽은 모델 없이 코드로 그린다(화면조정 무늬 캔버스).
- **소품(고정)** (완료): `massage_chair`, `sikhye_fridge`, `charging_locker`, `comic_shelf`, `washer`, `ice_pipes`, `hourglass`. 문 위 온도 표시판, 불가마 온도계, 벽시계, 엘리베이터 문은 모델 없이 코드로 그린다.
- **소품(물리)** (완료): `mat`, `mokchim`, `egg`, `sikhye_can`, `hinoki_ball`, `foot_bucket`, `laundry_cart`, `straw_mat`. 양머리 수건은 굴러다니는 소품이 아니라 매트 위에 가지런히 놓인 파편이라 4단계로 옮겼다.

`COL_*` / `ANCHOR_*` 이름 규칙을 지키고, `scripts/build-assets.mjs`의 `MOBILE_VARIANT_SPACES`에 `jjimjilbang`을 추가한다.

### 성능

- 테마방 4개(30 m), 수면실(46 m — 홀 전체에서 문 너머로 보인다), 세탁실(32 m)은 `DistanceLod`로 렌더를 끈다(콜라이더는 유지). 조명은 LOD 그룹 밖에 둔다 — 함께 꺼지면 조명 수가 바뀌어 셰이더가 다시 컴파일된다.
- 매트·목침·토굴 모듈·신발장 칸은 `GltfInstances`로 인스턴싱한다.
- 방마다 색이 다른 조명은 방 안 포인트 라이트 1~2개 + 발광 재질로 처리하고, 골목에서는 문틈 발광 면만 보이게 한다.
- `quality: 'low'`에서는 얼음방 안개 입자를 줄이고 N8AO를 끄며, 포인트 라이트를 26개에서 14개로 줄인다(`FillLight only`, `Lamp lit`): 문틈 보조광·TV·매점·아궁이 빛을 빼고, 홀 등 넷은 둘로, 통로 등 셋은 하나로 바꾼다.

### 플랫폼

새 입력이 없으므로 터치·키보드·게임패드가 그대로 동작한다. 사람 형상과 노출이 없고 글자는 숫자·표지뿐이라 현지화 부담과 등급 위험이 낮다.

## 8. 단계

| 단계 | 내용 | 끝났다고 보는 기준 |
|---|---|---|
| 0 | `core` 리팩터링(Water, Steam, kit 추출), 공간 등록, PRD에 찜질방 절 추가, AGENTS.md 구조 목록 갱신 | `npm run build` 통과, 센토 화면 변화 없음, `?space=jjimjilbang`에서 빈 바닥에 스폰 |
| 1 | 화이트박스: 6개 구역 박스 배치, 콜라이더, 고리 동선, 족욕 수로 물 영역 | 한 바퀴를 막힘 없이 돈다. 수로에서 느려진다 |
| 2 | 표면 재질·랜드마크 모델(불가마 볼트, 토굴 벌집, 카운터, 신발장), 방별 조명, 후처리 | 방 4개가 빛 색만으로 구분된다 |
| 3 | 물리 소품과 시드 배치, 수면 셰이더, 얼음방 안개, 부력 | 재시드해도 랜드마크는 그대로이고 소품만 달라진다 |

## 9. 이변 찾기 모드 카탈로그 초안 (PRD 14절)

고리: 입구 → 골목 → 홀 → 수면실 → 직원 통로 → 카운터 뒤 문 → 입구. 카운터 표시는 카운터 걸이의 열쇠 팔찌 개수(0~8).
모드 자체(`src/core/anomaly`, `SpaceDefinition.anomaly`)는 아직 없다. 아래는 그 모드가 생겼을 때 `AnomalyDef.apply`가 건드릴 곳까지 적은 초안이다. 전부 되돌릴 수 있는 변경이고, 사람 형상·소리로 놀래키는 것은 없다.

| 세기 | 이변 | 건드리는 곳 |
|---|---|---|
| 약함 | 문 위 온도 표시판 하나가 다른 방의 색이다 | `AlleyZone` 표시판의 emissive |
| 약함 | 신발장 열쇠가 하나 더 꽂혀 있다 | 신발장 앞에 열쇠 메시 하나 추가 |
| 약함 | 모래시계 하나만 모래가 흐른다 | 소금방 모래시계 하나의 모래 메시 높이 |
| 약함 | 골목 시계가 홀 시계와 같은 시각이다 | `JjimFragments` 시계 텍스처 교체 |
| 약함 | 요금표의 주간·야간 요금이 서로 바뀌었다 | 요금표 텍스처 교체 |
| 약함 | 외상 메모의 마지막 글자가 다 채워졌다 | 메모 텍스처 교체 |
| 중간 | 소금방과 황토방의 빛 색이 바뀌었다 | `ThemeRoom` 조명·발광 색 |
| 중간 | 안마의자가 전부 멈췄다 | `MassageChairs` 동작과 롤러 소리 |
| 중간 | 수로의 편백 볼이 한 줄로 늘어서 있다 | `createJjimDecor`의 channel 배치 |
| 중간 | 식혜 냉장고가 꽉 차 있다 | 냉장고 선반에 캔 인스턴스 추가 |
| 중간 | 라디오 반주가 거꾸로 흐른다 | `JjimAudio` 선율 순서 |
| 중간 | 불가마 온도계 바늘이 붉은 구간 끝에 붙어 있다 | `KilnGauge` 바늘 각도 |
| 중간 | 세탁기가 전부 돌고 있다 | `Washers` 회전 대상 |
| 강함 | 매트가 전부 TV를 등지고 있다 | `createJjimDecor`의 hall 매트 방향 |
| 강함 | 토굴 등이 전부 켜져 있다 | 굴 안 발광 판(조명 수는 그대로 둔다) |
| 강함 | 얼음방 안개가 위로 오른다 | `Steam`의 `rise` 부호 |
| 강함 | TV 세 대가 서로 다른 무늬다 | `TvWall` 화면 텍스처 |

희귀 이변 후보(확률 1~2%): 수로 수면 아래로 센토의 푸른 타일이 보인다.

## 10. 정해야 할 것

1. **공간 이름과 배경**: 호텔 지하 스파로 갈지, 동네 상가 건물 찜질방으로 갈지. 이 문서는 입구만 호텔 카펫이고 안쪽은 동네 찜질방 정서로 썼다.
2. **센토와의 연결**: 분실물 상자의 케로린 바가지 정도로 암시만 할지, 아예 연결하지 않을지.
3. **kit 추출 범위**: 0단계에서 `BathKit`을 얼마나 `core`로 올릴지. 최소안은 `Water`·`Steam`만 옮기고 박스 키트는 찜질방용으로 새로 작게 쓰는 것이다.
